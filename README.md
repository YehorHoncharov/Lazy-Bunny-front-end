# Lazy Bunny – Фронтенд для платформы просмотра фильмов

## Описание проекта

Lazy Bunny – это интерактивный веб-сайт для поиска и просмотра информации о фильмах. Проект был разработан в рамках изучения клиент-серверной архитектуры как часть дипломной рабооты. Данный репозиторий содержит фронтенд-приложение, созданное с использованием React.

Приложение позволяет пользователям регистрироваться и авторизовываться, вести список просмотренных фильмов, ставить оценки, комментировать, а также использовать страницу администратора и редактировать страницы фильмов и базу данных.

## Функционал

- Авторизация и регистрация
- Профиль пользователя
- Каталог фильмов
- Написание коментариев
- Администрирование фильмов
- Адаптивная верстка

## Технологии и стек

- Язык: TypeScript
- Фреймворк: React
- Роутинг: React Router
- Состояние: React Context
- Форма: useForm Hook
- Стили: CSS
- Запросы:  Fetch
- Аутентификация: JWT
